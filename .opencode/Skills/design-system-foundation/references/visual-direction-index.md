## Selection Rules

- Select one primary reference that best matches product category, primary users, and launch-critical surfaces.
- Select at most one secondary reference when it clarifies typography, component treatment, or atmosphere without conflicting with the primary reference.
- Reject references that weaken accessibility, density, trust, or workflow clarity for launch-critical screens.
- Convert selected references into structured design-system decisions before UI blueprints apply them.
